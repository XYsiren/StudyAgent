# 学习与复习模式：实现与验证

本次依据 `learning-assistant-development.md` 实现个人课程的学习、练习和复习闭环，沿用现有账号、知识库权限、资料版本、清理队列和模型适配器。

## 使用入口

登录后选择侧栏「学习与复习」，或访问 `/courses`。创建课程必须填写名称和考试日期；考试名称默认使用课程名称，每周预算默认 300 分钟。可关联自己的现有个人知识库，已有索引无需重建。课程删除会删除关联知识库及资料，界面有明确确认提示。

课程页面包括：概览、资料、大纲、学习计划、引用问答、练习、错题、间隔复习、学习数据。地址遵循 `/courses/:id/{materials,outline,study-plan,tutor,practice,mistakes,review,analytics}`。

## 已实现

- 课程 CRUD、考试日期/预算变更、过期考试提示；自动建立基础计划，资料索引完成后补充具体任务。
- SQLite/PostgreSQL 共用的增量迁移 `007_learning`。课程、章节、知识点、题目、作答、复习卡、任务、事件和出题作业使用独立表。
- 章节树、手动知识点、从资料标题提取的待确认建议、编辑、重要程度、来源关联、合并和拆分。未确认建议不会自动进入计划。
- 课程上传复用现有文档服务和配额。PPTX 提取标题、段落、表格、备注、替代文本，保留幻灯片编号、页面类型、未解析对象数量。`.ppt` 明确提示转换。
- PPTX 限 300 页和解压后 200 MiB；损坏/超限文件拒绝。纯图片幻灯片缺少视觉能力时保留图片预览并进入 `vision_pending`，不发布部分索引；配置能力后可重试。
- 幻灯片引用使用 `slide_number`、`page_label`，PDF 仍使用 `page`。来源视图按文档版本读取幻灯片元数据，避免资料替换后串页。
- 课程范围内的 SSE 引用问答、章节/知识点限制、讲解/举例/对比/练习引导。复用现有检索、限流、会话租约、来源校验和请求幂等；不能复用其他课程会话。
- Worker 异步生成单选、判断、简答草稿；任务可查询、取消、重试、回收过期租约。保存来源、模型、提示词版本、范围/版本/参数签名。引用原文和答案约束失败时跳过并记录原因，不将草稿自动批准为正式试题。
- 作答幂等，记录耗时、信心、用户错因与单独的系统建议错因。单选/判断使用答案比对；简答题明确需要对照原文自查，不自动计入正确率。
- 错题本、修改错因、题目反馈、再练习、题目人工批准/拒绝。失效、过期或被替换来源的题目不会继续出现在练习、错题和复习列表。
- Leitner 复习间隔为 1/2/4/7/14/30 天，支持太简单/记得/模糊/不会，重复提交复习评分不重复升级。按每日预算限制任务完成及复习数量。
- 今日任务、完成/跳过/无法完成/调整时长、重建计划。重建仅替换 pending 任务，保留历史记录。
- 指标携带 value/sample_size/period/definition_version/definition，小样本提示；支持 JSON 导出课程、知识点、计划、练习、作答、错题和复习记录。
- 同知识点的独立题目前后测；同一道题不能同时用于该用户的前测和后测；差异只作为过程指标，不包装为考试成绩变化。

## 明确边界

- 当前为个人学习模式，不包含设计稿 Phase 4 的小组共享、助教审核、手写笔记专用识别、语义冲突检测及 A/B 实验平台。保留原有团队治理功能，未将其直接作为课程共享权限。
- 当前题型优先实现文档要求的单选、判断、简答；多选和填空留待扩展。
- 知识点建议采用可解释的资料标题规则，不依赖额外模型调用。合并/拆分后的来源可以手动进一步调整。
- 对象动画、音视频、嵌入对象不会执行或下载；没有完整的 Office 渲染器。图片页预览是内嵌图片预览，不承诺还原完整幻灯片版式。文本页图片未描述时明确计入未解析对象。
- 引用摘录校验不是完整语义证明。判断题和复杂解析需要人工核对，所有模型题目默认 draft。
- 简答评分采用人工自查，尚未提供教师评分工作流；不会伪造模型分数。
- 复习是站内到期任务，不会向外部邮件/消息服务发送提醒。
- 学习正确率只统计来源仍有效的已判定作答；引用覆盖率是“有引用回答比例”，不是人工逐结论事实核验率。
- 最小验收数据中的 50 道人工检查题、20 条人工标注错题和长期效果实验，需要真实人工标注；自动测试不会冒充这些人工结果。

## 本地运行

```bash
bash scripts/start-local.sh
```

服务使用 `.env`、`.venv` 和 `data/tools` 中的便携式 Node/Python。数据保存在 `data/local`。服务器仍通过 SSH 转发在电脑浏览器访问：

```bash
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -L 15173:127.0.0.1:5173 xuyi@服务器地址
```

打开 `http://localhost:15173/courses`。保持转发终端打开。
