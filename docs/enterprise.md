# 团队治理与可靠性

知衡围绕组织协作、知识更新、证据质量与故障恢复提供工程能力。本文说明操作方式、验证证据和部署边界。

## 能力与验收

| 方面 | 当前能力 | 验证方式 |
| --- | --- | --- |
| 组织与权限 | 组织成员、管理员/编辑/只读角色；全员或指定成员知识库；文档继承知识库授权；撤权后隐藏历史来源 | 跨账户、跨组织、受限知识库、缓存及历史撤权回归 |
| 检索规模 | 入库时保存 BM25 倒排词频；SQL 内评分；Qdrant 按授权知识库预过滤；仅回查命中候选 | 持久索引回归、5000 分块容量探测 |
| 数据一致性 | 删除事务提交可重试清理任务；向量写入租约围栏；过期任务恢复；孤立向量对账 | 模拟向量服务故障、真实 PG/Redis/Qdrant 集成回归 |
| 回答质量 | 来源编号与数字检查；可选 LLM 事实核验；证据不足拒答；未通过核验回退原文摘录 | 30 条合成业务题、本地模型代表案例、真实 Ragas 四指标 |
| 安全与预算 | 可撤销服务端会话、HttpOnly Cookie、跨站检查、登录/问答限流、个人与全局并发上限、容量和任务预算 | 令牌撤销、CSRF、限流、容量、并发与幂等回归 |
| 文档生命周期 | 更新文件生成新版本；旧版持续服务；新索引就绪后切换；历史版本恢复；有效期；目录增量同步 | 更新中查询、恢复旧版、失效缓存和目录边界回归 |
| 运维与交付 | Alembic 迁移、独立摄取/评测 Worker、依赖与模型探针、Prometheus 指标、备份校验及恢复 | 镜像/编排检查、完整恢复后重新查询和原文下载 |

可复现结果见[验证记录](validation.md)。合成题集和单机探测用于功能回归，不代表任意企业资料上的准确率、并发容量或 SLA。

## 组织与知识库授权

在“团队与治理”创建组织，按已注册邮箱添加成员。在“知识空间”创建知识库时选择所属组织和可见范围。

| 角色 | 读取、问答、下载 | 上传、更新、重建、过期文档 | 成员授权、删除知识库 |
| --- | --- | --- | --- |
| 只读成员 | 是 | 否 | 否 |
| 编辑 | 是 | 是 | 否 |
| 管理员 | 是 | 是 | 是 |

全员可见知识库继承组织角色。指定成员可见知识库只开放给明确授权成员；组织管理员负责管理组织内的知识库。知识库授权不能将组织外账户引入内部资料。移除组织成员会清理其单独授权并撤销现有登录会话；单独撤销某知识库授权保留该成员的登录和其他知识访问。

每次检索重新使用当前权限条件。历史回答、评测和幂等重放也核对来源权限，避免通过旧记录继续读取已撤销的团队知识。用户已下载到本地的资料不在服务端撤权控制范围内。

## 企业单点登录

支持 OIDC Authorization Code + PKCE（S256），校验签名、issuer、audience、有效期、nonce 和多 audience 的 azp；登录 state 一次性消费并绑定浏览器 Cookie。新身份要求已验证邮箱，不按相同邮箱静默绑定原密码账号。

```dotenv
RAG_PUBLIC_BASE_URL=https://knowledge.example.com
RAG_COOKIE_SECURE=true
RAG_CORS_ORIGINS=["https://knowledge.example.com"]
RAG_OIDC_ISSUER=https://identity.example.com/realms/company
RAG_OIDC_CLIENT_ID=knowledge-assistant
RAG_OIDC_CLIENT_SECRET=configure-locally
RAG_OIDC_REDIRECT_URI=https://knowledge.example.com/api/auth/oidc/callback
```

身份服务需要登记精确回调地址，并开放 `openid email profile`。完成管理员初始化后，可设置 `RAG_ALLOW_REGISTRATION=false` 关闭公开密码注册。回调完成后使用服务端会话，浏览器通过 HttpOnly Cookie 请求 API。协议回归使用真实 RSA 签名和模拟身份服务；具体企业 IdP 的连接、账号生命周期和登出策略需要在其环境验收。实现依据 [OIDC Core](https://openid.net/specs/openid-connect-core-1_0.html) 和 [PyJWT 文档](https://pyjwt.readthedocs.io/en/latest/usage.html)。

## 回答核验与评测

问答先提取问题主题，独立的新问题不自动拼接上一轮话题。检索结合正文、文档标题与知识库主题，过滤 Markdown 导航链接和课程宣传片段；代码或定义被分块切开时，只在同页、同活动版本和同授权范围内补全相邻片段。

生成后按事实原句编号核验，来源也使用显式编号，防止核验时误换主语或混淆数据库标识。概念题优先简洁解释，产品实例不能直接泛化成整个概念的特性。核验失败时最多修订一次，仍失败则拒答或返回标注的原文；未通过核验的结果不进入答案缓存。代码中的数组下标与来源编号分别处理。

单项数值查询会按正文中的指标词过滤泛词匹配；模型核验同时检查逐句证据支持和问题相关性。有部分句子已通过核验时，优先保留其原句并再次核验，避免重写时带回无关指标。最终来源列表只保留答案实际引用的证据，引用编号同步更新。核验依赖所选模型，仍需结合业务题集与原文抽查。

明确命中章节标题的条款查询，按该章节及其子条目取证，到同级或更高层级章节结束，不把只有标题的片段当作答案。条款列表保留数值、单位、标准编号和适用条件，不应用概念解释的两句限制；回退摘录同样保留完整条目。单位或标准编号紧邻引用时先规范格式，代码数组下标仍独立处理。

`RAG_CITATION_VERIFIER=numeric` 检查来源编号及引用原文中的数字，属于部分校验，不判断完整语义蕴含。`llm` 模式额外判断来源是否足以回答问题，以及事实、条件和单位是否受引用支持。

```dotenv
RAG_CITATION_VERIFIER=llm
RAG_VERIFIER_MODEL=
RAG_EVIDENCE_MIN_COVERAGE=0.25
```

未指定核验模型时复用当前生成模型；可指定独立模型名称。核验调用异常或无法确认问题可回答时，系统保守拒答；不支持的生成内容回退为明确标注的原文摘录。界面中的实时文本标注为“待引用校验”，完成后用最终核验结果替换，不保存未通过的草稿。

词项覆盖阈值是可配置启发式，可能影响同义改写与低词面重合问题的召回，需要用业务题集校准。LLM 核验与 Ragas 都不能替代人工抽查。仓库提供 30 条合成业务案例，覆盖数字、无答案、过期制度、恶意文档和跨文档问题：

```bash
python scripts/benchmark.py --load-chunks 5000 --queries 40 --output artifacts/benchmark.json
python scripts/benchmark.py --mode configured --case-indices 0,1,4,24,28,29 --output artifacts/benchmark-model.json
```

实际业务验收还应加入真实问题、难扫描件、表格、长文档、权限对抗、版本冲突和人工标注，并按业务风险设定质量门槛。

## 配额、流式请求与异步评测

部署方通过 `RAG_PLATFORM_ADMIN_EMAILS=["owner@example.com"]` 指定平台管理员。账号需先注册；此权限不由前端或组织角色自行授予。登录后在“团队与治理 → 平台管理”选择全局默认或具体账号，调整存储、待处理任务、问答并发和每日请求预算。保存后持久化到 SQL，新请求立即生效，无需重启；已经运行的请求保持原配置。

账号单独配置可恢复为继承全局默认。整个服务的问答并发始终由全局控制，账号配置不能覆盖它。平台管理权限用于配额与任务运维，检索和问答仍遵循个人、组织及知识库访问策略。

任务列表按摄取、评测、清理分类，显示状态、阶段、页数、错误和租约。取消摄取任务保留原件及已发布版本；重试会创建新修订并重新索引。清理任务不能取消，防止遗留应删除的资料；失败或租约过期时可重试。正在调用的模型会在返回或超时后退出，取消不会强制终止整个模型服务。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `RAG_AUTH_RATE_PER_MINUTE` | 20 | 每来源地址每分钟登录/注册请求 |
| `RAG_CHAT_RATE_PER_MINUTE` | 30 | 每账户每分钟问答请求 |
| `RAG_USER_STORAGE_MB` | 1024 | 知识库所有者承担的原件与版本文件配额 |
| `RAG_MAX_PENDING_JOBS` | 20 | 所有者范围内待处理摄取任务 |
| `RAG_MAX_ACTIVE_CHATS` | 2 | 每账户同时问答上限 |
| `RAG_GLOBAL_ACTIVE_CHATS` | 4 | API 全部副本共享的同时问答上限 |
| `RAG_USER_DAILY_MODEL_REQUESTS` | 500 | 每账户每天请求预算单位 |

同一原件用于重新索引或恢复时不重复计费；删除后尚未清理的文件继续占用配额。

预算单位为普通问答 1、普通评测每案例 1、Ragas 每案例 6，包含缓存请求的准入预算，不是精确 token 计费；实际生成与核验用量保存在运行元数据。前置可信代理需要正确配置客户端地址，避免把全部用户视为一个来源。

浏览器使用 `/api/chat/stream` 的真实模型流，支持停止生成。相同 `request_id` 的已完成问答可幂等重放；请求体改变、正在执行或证据失效时返回冲突。同一会话同时只允许一个生成轮次。取消在接收到下一段模型数据或达到供应商时限时释放上游调用。

`POST /api/evaluations` 返回 `202` 和运行 ID；通过 `GET /api/evaluations/{id}` 轮询。Compose 将摄取和评测分配给独立 Worker。评测期间语料或权限变化会使运行失败，防止使用不同版本比较结果。

## 文档版本与目录同步

文档列表的“版本与有效期”入口支持上传新版本、查看状态和恢复历史版本。新文件解析或索引失败时，原活动版本继续参与检索。来源引用保存版本 ID，下载历史引用时读取对应版本原件。

删除文档使用页面确认框，等待期间显示操作状态，处理中任务会失去写入租约。PDF 默认优先提取原有文字层；只有文字不足的图片页执行 OCR 或视觉识别，避免对长文档重复逐页推理。需要额外逐页视觉理解时可设置 `RAG_PDF_VISION_ALL_PAGES=true`，相应耗时会增加。解析回调和向量批次检查取消状态，进度展示不再停留在开始阶段。

目录连接器只访问管理员配置的根目录，拒绝越界路径和越界符号链接。每次最多同步 100 份支持的文件；按 SHA256 跳过未变化内容，变化内容形成新版本。

```dotenv
RAG_SOURCE_SYNC_ROOT=/srv/knowledge-source
```

容器部署需额外把该目录以只读方式挂载给 API。通过“团队与治理 → 同步文档源”选择目标知识库和根目录内相对路径。源文件移除时保留历史知识，需显式设置过期或删除，防止误同步造成资料丢失。当前连接器覆盖文件目录；飞书、SharePoint 等服务需要实现各自的鉴权、增量事件及权限映射。

## 生产验收边界

当前交付包含工程能力与可重复验收流程。组织架构/部门同步、企业 IdP、远端文档源、HTTPS 入口、告警通知渠道、异地加密备份目标，仍需结合实际企业环境配置。当前 Compose 使用单实例存储与共享卷；跨主机高可用需要规划共享对象存储、数据库及向量服务副本，并完成业务负载与故障演练。
